## 审计目标

比较候选项目的可复用性、正确性、许可证和算法口径，为 Chat 提供可审核证据。任何审计结论必须先经 Chat 明确批准，才能进入 `bazi_rules_v1.md`。

## 待确认审计范围

- 候选项目清单及优先级；
- 关注的算法模块；
- 权威交叉验证来源；
- 金标案例规模和通过标准；
- 允许直接复用、仅参考或禁止复用的边界。

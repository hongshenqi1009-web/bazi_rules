# 用户流程

- 状态：框架/待验证
- 最后更新：2026-09-09

## 主流程占位

`入口 → 产品说明与娱乐声明 → 出生信息 → 时间/地点校验 → 计算 → 五行解释 → 城市探索 → 分享/保存 → 可选深度内容`

该流程仅定义产品结构，不确认任何算法、字段、排序或付费方案。

## 必须覆盖的状态

- 出生时间精确、模糊或未知；
- 城市同名、历史时区、夏令时和边界情况；
- 候选盘或低置信度；
- 城市数据不足；
- 计算失败、恢复与重试；
- 分享前隐私预览；
- 删除数据与撤回同意。

## 待验证

- 输入字段和步骤数量；
- 首屏价值说明；
- 结果信息层级；
- 城市推荐数量和解释深度；
- 分享与复访方式；
- 付费墙位置和内容。

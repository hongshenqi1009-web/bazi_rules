# 《山河有应》免费版用户流程

- 状态：T-007 可实施规格
- 最后更新：2026-09-12
- 设备基线：手机竖屏优先，桌面端居中单列适配

## 1. 主流程

`首页 → Step 1 出生日期/时辰 → Step 2 出生地点/性别 → 两段式推演 → 结果一 五行属性/城市能量 → 结果二 Top 3 → 城市详情 → 分享预览/导出`

用户返回上一页时保留本次会话输入；刷新、过期或主动退出时按隐私策略清理。MVP 不设置独立信息确认页，不收集姓名，也不要求注册。

## 2. 首页

### 内容顺序

1. Logo / 品牌名：**山河有应**；
2. 主标题：**找到与你能量最契合的城市**；
3. 副标题：**循着你的出生轨迹，寻找命盘所回应的城市。**；
4. CTA：**开始探索**；
5. 首屏底部保留简短“娱乐体验”入口，不在主视觉周围堆解释小字。

### 交互

- 点击 CTA 进入 Step 1；
- 主视觉圆环、星轨和世界地图处于持续但克制的环境动态；
- 系统启用减少动态时，替换为静态层叠与淡入。

## 3. Step 1：出生日期与出生时辰

### 字段

- `出生日期`：必填，使用用户出生地的当地民用日期；
- `出生时辰`：必填其一：12 时辰、`不确定`、或次级入口的精确时间。

### 十二时辰圆盘

- 环形显示 12 时辰，中心显示当前选择；
- 每项同时显示时辰名与民用时间范围，例如 `未时 13:00–14:59`；
- `不确定`作为同等可达选项，但视觉弱于 12 时辰；
- 提示：**出生时辰会影响时柱及部分五行判断；不确定也可以继续，我们会生成简化结果。**

### 精确时间入口

次级入口文案：`我知道精确出生时间`。展开后输入 `HH:mm`，取代时辰圆盘选择；用户可切回时辰模式。

### 子时必要分辨

由于产品正式采用 23:00 子初换日，只选择`子时`而没有精确时间时，在本步骤内追加：

- `23:00–23:59`；
- `00:00–00:59`；
- `不确定`。

选择前两项可确定民用日期归属；选择“不确定”则返回两种候选盘或简化结果，并降低置信度。该控件不是新增页面，也不采用混合换日模式。

### 校验与动作

- 日期超出支持范围时说明当前可计算范围，不静默修正；
- 未来日期、非法日期或无选择时禁用“继续”并给出就地提示；
- 点击`继续`进入 Step 2。

## 4. Step 2：出生地点与性别

### 出生地点

- 搜索城市名，结果显示`城市 · 地区 · 国家/地区`；
- 用户必须从标准结果中选择，不能只提交自由文本；
- 选择后后台保存稳定地点 ID、国家/地区、WGS84 经纬度、IANA 时区和数据快照版本；
- 同名城市必须显示地区层级，不替用户猜测；
- 无结果时提供“换一种拼写”与反馈入口，不允许手填经纬度作为普通流程。

### 性别

- 必填：`男` / `女`；
- 辅助说明：`仅用于传统大运顺逆计算`；
- 接口把它作为算法参数，不把结果文案扩展为身份判断。

### 摘要与提交

页面底部实时显示一行摘要，例如：`2000.10.09 · 未时 · 青岛`。精确时间显示 `14:26`；不确定时显示`时辰不确定`。不设独立确认页。

主按钮固定为：**探索你的城市能量**。

## 5. 推演页

动画不设置虚假固定时长，完全由任务状态驱动。

### 阶段一：推演五行关键属性

- 五行圆盘启动并逐步点亮；
- 显示少量状态词，如`校准出生轨迹`、`辨识五行流向`；
- 不提前显示类型名、喜忌或城市结果。

### 阶段二：搜索回应的城市

- 地球缓慢转动，世界地图和城市光点显现；
- 光点从分散变为收束；
- 状态词如`连接山海气息`、`寻找相合的城市`。

### 长等待与失败

- 处理较慢时继续展示真实阶段，不伪造百分比进度；
- 超过体验阈值后显示`仍在推演，请稍候`；
- 可重试错误不得丢失输入；不可恢复错误提供返回修改入口和追踪码；
- AI 城市文案超时不阻塞核心结果：先显示结构化结果和模板文案，稍后补充或保持降级版本。

## 6. 结果第一页：你的五行属性与城市能量

### 首段：你的五行属性

按顺序渐进展示：

1. 五星/五行圆形主视觉，不显示百分比；
2. 高级类型名，例如`木水相生型`；
3. 强弱层级，例如`木偏强 · 水次之 · 土平衡 · 金较弱`；
4. 一句解释，例如`木水相承，气质柔韧而流动。`。

类型名和强弱句必须由结构化规则标签或受控模板生成。若置信度较低，使用`较偏向……`、`目前更接近……`等表达，并提供简短说明入口。

### 过渡：星轨能量线

五行区域完成后，暗金星轨线从上向下展开，带少量碎闪，连接到城市能量区域。页面首次进入时不得让上下两部分同时完整出现。

### 次段：更契合你的城市能量

- 使用更轻、更淡的五行轨迹图，不显示第二套复杂强弱分析；
- 展示 2–3 句含蓄文案，包含五行倾向、环境气息和生活感受；
- 不使用`必须`、`注定`、`一定适合居住`等措辞；
- 免费版不显示“当前阶段”标题、卡片或大运术语。

主动作：`看看哪些城市回应你`，进入 Top 3。

## 7. 结果第二页：Top 3 城市

### 排序

- 完全按 Matching Engine 最终分数的稳定排序返回，不为娱乐性人工改位；
- Top 1、Top 2、Top 3 依次浮现；Top 1 只在尺寸、光晕或留白上轻度突出；
- 若属于同一 1.0 点梯队，保留真实次序并显示`与你同样接近`或`非常接近`，不夸大差距。

### 收起卡片

每张卡只显示：

- 名次和城市名；
- `契合指数 91`格式的整数指数，不显示百分号；
- 2–3 个 City Profile 核心气质标签；
- 打开详情的明确触点。

卡片打开采用翻页或展卷感，但应保持方向明确、可返回且支持减少动态模式。

### 页面动作

- 点击任一城市进入对应详情；
- 次动作：`生成我的城市回应卡`；
- 可返回结果一，不重新计算。

## 8. 城市详情

页面按以下顺序：

1. 城市名；
2. 契合指数；
3. 2–3 个气质标签；
4. 真实、知名、有地标感的城市主图；
5. `城市特色`；
6. `为什么契合`；
7. `它会带来的感受`；
8. 返回榜单与分享动作。

不显示城市五行小图。城市特色必须落到具体地理、气候、生活与少量辅助特征；为什么契合把个人结构与城市组合自然连接；感受段落以“用户已有优势更容易展开”为中心，不承诺结果，轻微冲突可柔和融入正文。

City Profile 或 AI 文案失败时，显示经审核的事实模板，不隐藏城市、指数或排名。

## 9. 分享预览与导出

分享前先展示完整预览，并说明不会包含出生日期、时辰、地点、性别或四柱。主卡包含：

- `你的城市能量，回应在这座城里`；
- Top 1 城市主视觉、城市名与契合指数；
- 一句诗意回应文案；
- Top 2 / Top 3 两行城市名与指数；
- 圆形星轨框内二维码；
- Logo 与`山河有应`。

用户可保存图片或调用系统分享。取消分享返回原页，不能丢失结果。

## 10. 关键分支与降级

| 状态 | 用户看到什么 | 系统行为 |
|---|---|---|
| 精确时间 | 正常体验 | 计算完整主方案 |
| 只知时辰 | 正常体验，精度说明较轻 | 按时辰口径计算；保留精度字段 |
| 子时段不确定 | `日界附近，结果可能有两种理解` | 主/辅助候选或简化结果，不混合计算 |
| 时辰完全不确定 | `仍可探索简化结果` | 不伪造时柱，降低置信度 |
| 低置信度/流派分歧 | `结果对口径较敏感` | 保存主辅方案；免费页不把两者平均 |
| 真太阳时可能改变时柱 | 轻量说明入口 | 默认仍用民用时间，高级模式可选 |
| 地点歧义 | 要求选择标准城市 | 不继续计算 |
| 城市文案缺失 | 简洁模板文案 | 排名和指数正常显示 |
| 城市图片缺失 | 品牌化地点占位图 | 不使用错误城市图片 |
| 计算失败 | 温和错误、重试、返回修改 | 保留输入与错误追踪码 |

## 11. 免责声明与隐私文案

入口短版：

> 本体验以传统五行文化与现代城市数据进行娱乐化表达，仅供探索与分享。

结果页短版：

> 契合指数是本产品的娱乐型模型指数，不代表概率，也不构成迁居、职业、投资、健康或其他现实决策建议。

分享预览短版：

> 分享卡不会显示你的完整出生信息。

方法与隐私页需进一步说明算法口径、候选性质、资料用途、会话期限、删除方式和联系方式。

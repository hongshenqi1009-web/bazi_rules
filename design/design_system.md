# 《山河有应》Design System v0.2

- 状态：T-009 视觉资产生产基线
- 最后更新：2026-09-15
- 适用范围：免费娱乐传播版 MVP
- 参考管理：`design/references/README.md`

## 1. 品牌核心

品牌名：**山河有应**。

关键词：**高级、简约、东方、玄学宇宙、细线、碎闪、暗金、墨绿、有仪式感**。

品牌叙事不是“替用户预言命运”，而是让出生轨迹、五行流动与城市山河产生含蓄回应。视觉应有面纱感和余韵，不把算法、术语和装饰同时堆满屏幕。

反关键词：传统算命摊、寺庙红金、廉价星座测试、游戏升级面板、赛博霓虹、信息仪表盘、堆满英文坐标与无意义小字。

## 3. 色彩系统

以下为可实施初始 token；最终应结合参考图和真机对比度微调，但不得改变墨黑/墨绿/暗金主体系。

| Token | 建议值 | 用途 |
|---|---|---|
| `ink-950` | `#050A08` | 页面最深背景 |
| `ink-900` | `#081310` | 主背景 |
| `jade-900` | `#0D241D` | 卡片与渐变 |
| `jade-800` | `#14362B` | 选中态/局部层次 |
| `gold-500` | `#B9985A` | 主暗金线与 CTA 边缘 |
| `gold-300` | `#D8C18B` | 高光与重要文字 |
| `mist-100` | `#E9E5D8` | 主文字 |
| `mist-300` | `#B8B7AD` | 次文字 |
| `mist-500` | `#7C827B` | 禁用/弱提示 |
| `error-400` | `#C77B70` | 温和错误，不使用高饱和红 |

背景建议由 `ink-950 → jade-900 → ink-900` 的大面积低对比渐变构成。金色不用于整块填充，只用于线、边、星点、少量标题和聚焦状态。

### 五行局部高光

五行色只影响圆盘节点、局部光晕或碎闪，面积不超过单屏视觉色彩的约 12%。

| 五行 | 建议高光 | 非颜色编码 |
|---|---|---|
| 木 | `#6F9B78` | 生长弧线/叶脉细纹 |
| 火 | `#C9825A` | 向上微光/尖角星芒 |
| 土 | `#A98B62` | 稳定同心层/方圆交叠 |
| 金 | `#C7BFA9` | 清晰切面/短直线 |
| 水 | `#628F95` | 流线/波纹 |

任何信息都不能只靠颜色区分。

## 4. 字体与排版

### 字体策略

- 中文展示标题：候选为思源宋体 / Noto Serif SC，自托管并核验开源许可；
- 中文正文与控件：候选为思源黑体 / Noto Sans SC，自托管；
- 数字指数：与正文同家族或使用克制的衬线数字，不引入明显西式奢侈品牌感字体；
- 不依赖境外字体 CDN，必须有系统字体回退。

建议字体栈：

```text
serif: "Noto Serif SC", "Source Han Serif SC", "Songti SC", serif
sans: "Noto Sans SC", "Source Han Sans SC", "PingFang SC", "Microsoft YaHei", sans-serif
```

### 移动端层级

| 层级 | 字号/行高 | 用途 |
|---|---|---|
| Display | 34/46 | 首页主标题、类型名 |
| H1 | 28/40 | 页面标题、城市名 |
| H2 | 22/32 | 内容模块标题 |
| H3 | 18/28 | 卡片标题 |
| Body | 16/28 | 主要正文 |
| Small | 14/22 | 标签、说明 |
| Caption | 12/18 | 许可、辅助提示，避免大量使用 |

最小正文不低于 14 px。标题字距可略放宽，正文不使用大段居中；诗意短句可居中，事实段落左对齐。

## 5. 间距、布局与容器

- 基础间距单位：4 px；常用序列 `4/8/12/16/24/32/48/64/96`；
- 手机设计基准：375 × 812；支持 320–430 宽度；
- 页面左右安全边距：24 px，窄屏可降到 20 px；
- 内容正文最大宽度：640 px；桌面保持单列，不横向摊成仪表盘；
- 区块垂直间距：48–80 px；仪式性主视觉可使用 96–128 px；
- 卡片圆角：16–24 px；边线 1 px、低对比暗金；
- 按钮最小触控高 48 px，主要 CTA 52–56 px；
- 标签保持单行短词，不用多排彩色胶囊制造噪声。

## 6. 表面、线条与质感

- 卡片底：半透明深墨绿，轻微内高光；
- 阴影：宽、淡、偏冷黑；不用厚重浮层阴影；
- 线条：0.75–1.25 px 暗金，关键轮廓可局部提亮；
- 碎闪：少量、大小不一、非均匀撒点；
- 墨雾：大尺度低频纹理，透明度保持极低；
- 世界地图：仅作意象轮廓，不加城市缩写或密集坐标；
- 星轨：承担“连接”和“流动”，不作为所有卡片的背景装饰。

## 7. 核心组件

### 首页 Hero 圆盘

五行命盘、圆形星图与淡世界地图融合。中心聚焦但不放多余说明文字；主标题、副标题和 CTA 与圆盘保持呼吸。地图不得抢过圆盘。

### 十二时辰圆盘

12 时辰沿圆周均匀排布，中心显示选择，暗金细线连接。`不确定`置于圆盘外但保持同一视觉系统；精确时间为次级文本入口。选择子时后追加的时间段控件使用同页底部抽屉。

### 五行属性圆

五行是主视觉，不显示百分比。相对层级通过节点大小、光晕、线条明暗和视觉深度表达，同时给屏幕阅读器提供文字强弱句。

### 星轨能量线

从个人五行区向下绘制一条可见的暗金/星光轨迹，带少量碎闪，完成后再揭示城市能量段落。它是叙事连接，不是分割线。

### 城市榜单卡

收起态只含名次、城市、契合指数、2–3 标签和打开动作。Top 1 可放大约 4–8%，Top 2/3 仍保持完整视觉质量。展开使用翻页/展卷感，减少动态模式改为淡入与高度展开。

### 城市详情

有清晰城市辨识度的主图占视觉主导，不叠复杂地图、密集英文小字或城市五行图。主图可采用经过审核的授权摄影或从零生成的正式城市意象图；两者都必须经过城市识别、来源和使用边界审核，且不得将生成图冒充纪实摄影。内容块按“城市特色 → 为什么契合 → 它会带来的感受”排列，使用留白而非大量边框分区。

### 分享卡

3:4 竖版，城市能量和 Top 1 为主角。Top 2/3 仅两行；二维码置底部圆形星轨容器。完整规格见 `product/free_result_and_share_spec.md`。

## 8. 动效系统

动效目标是“缓慢苏醒、流动、回应”，不是炫技。

- 环境圆环：24–48 秒一周，线性、低存在感；
- 星点：不规律呼吸 2.4–5 秒，避免同步闪烁；
- 页面揭示：单段 480–800 ms，`cubic-bezier(0.22, 1, 0.36, 1)`；
- 五行到城市过渡：1.2–2.2 秒，随滚动或状态触发；
- Top 3：每张间隔 180–260 ms，不能拖慢用户操作；
- 卡片展卷：420–680 ms；
- 推演动画不设固定总时长，由后端 `stage` 驱动。

减少动态模式：关闭持续旋转、视差、粒子漂移和路径绘制，改用 160–240 ms 透明度过渡；进度必须有文字状态。

## 9. 城市图片

- 城市地标或地域特征必须清楚、知名、构图优美；
- 详情页约 70% 城市美感 + 30% 品牌感；
- 品牌处理仅限暗角、轻微墨绿分级、细暗金轨迹或统一颗粒；
- 不再争论“真实照片 vs AI 图”的路线：授权照片与从零生成图均可进入候选，但必须明确类型；生成图不得冒充纪实照片、不得虚构地标或作为 City Profile 的事实证据；
- 每张图记录城市确认、来源/生成方式、作者或工具、许可/条款、焦点、替代文本、哈希和可用场景；
- 母版统一 1536 × 1024、3:2；核心地标在中央约 70% 安全区，兼容 4:3 和竖向裁切；
- 图内不预埋文字、Logo、二维码或复杂星轨，品牌叠加由前端统一完成；
- 关键图片不得依赖境外不可用热链。

T-009 首批 8 城生成图、提示记录和哈希见 `design/assets/README.md` 与 `design/assets/city-hero-prompts.md`。它们是上线候选，不是历史参考图；最终公开前仍须逐张完成品牌方、地标和适用条款验收。

## 10. 文案语气

语气：含蓄、温柔、有共鸣、有具体感、留有余地。

推荐：`回应`、`共振`、`更容易`、`可能`、`像是`、`舒展`、`流动`、`展开`。

禁用：`注定`、`必须`、`改命`、`最旺`、`绝对`、`去了就会成功`、恐惧式损失提醒。城市事实不得被诗性修辞替代。

## 11. 无障碍与可用性

- 正文和关键控件满足 WCAG AA 对比度目标；暗金小字须特别检查；
- 所有按钮和圆盘选项可键盘操作，有清楚焦点环；
- 12 时辰圆盘同时提供语义列表，不依赖环形位置；
- 五行、排名、加载状态和错误不只靠颜色或动画表达；
- 城市图片提供具体中文替代文本；纯装饰星点隐藏于辅助技术；
- 分享卡的二维码经过压缩后扫描验证；
- 支持系统字体放大到 200%，正文不截断。

## 13. 视觉验收清单

- 首屏只有品牌、主副标题、CTA 和核心圆盘，没有解释性小字堆叠；
- 五行个人页没有百分比；
- 城市详情没有城市五行小图；
- Top 1 只轻度突出，Top 2/3 不被视觉贬低；
- 城市图片仍是详情主角，星轨不过量；
- 五行高光变化不破坏统一品牌；
- 减少动态、键盘、屏幕阅读器和 200% 字号路径可用；
- 分享卡二维码可扫、无敏感出生信息；
- 参考图、Logo、字体和图片均有许可与本地可用资产。
- 若使用生成图，界面和资产台账不把它描述成摄影作品；地标形态与裁切已逐张审核。

# 视觉参考图清单

本目录保存 Chat 已确认的视觉参考原图及其来源记录。参考图只作为 art direction，不是像素级实现标准；最终页面以 `design/design_system.md`、产品规格、可用性和响应式要求为准。

## 目录

1. `01-home-hero/`：首页 Hero 最满意效果图；
2. `02-shichen-wheel/`：第一张十二时辰圆盘；
3. `03-five-element-profile/`：选定的图 1 五行圆形；
4. `04-energy-transition/`：B 星轨能量线；
5. `05-city-detail/`：早期第一版城市卡方向；
6. `06-logo/`：第二张圆形山水星轨 Logo。

当前原图尚未正式进入仓库，六个目录先以占位文件纳入版本控制。收到素材后使用稳定文件名，例如 `reference-01.png`，并在同目录补充 `METADATA.md`：

- 来源或原对话标识；
- 作者/生成方式；
- 使用权限；
- 确认日期；
- 页面用途；
- 重点参考；
- 不照搬内容；
- 文件 SHA-256。

不要把聊天截图或无来源图片直接当生产素材；生产用 Logo、字体、城市照片和纹理需另有许可记录。

分享卡不建立旧图参考目录，因为现有旧稿均未被确认。分享卡以新规格重新设计。
